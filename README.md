# Asafo Tech

Asafo Tech is a Ghana-focused electronics storefront built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Local development

```sh
npm install
npm run dev
```

The app runs on `http://localhost:8080`.

## Scripts

```sh
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```

## Setup Guides

Setup documentation lives in [docs/setup/README.md](C:\xampp\htdocs\e-commerce\docs\setup\README.md).

That file is auto-generated from the setup guide files inside [docs/setup](C:\xampp\htdocs\e-commerce\docs\setup) by [scripts/update-setup-readme.mjs](C:\xampp\htdocs\e-commerce\scripts\update-setup-readme.mjs).

For true live watching while editing setup guides, run:

```sh
npm run docs:watch
```

## Current status

This repository currently contains the storefront UI and supporting frontend setup. Product data, authentication, orders, payments, and admin features still need to be connected to a real backend.
